# Web Scraping with BeautifulSoup

Mini projet de parsing HTML développé en Python.

## Description

Ce script utilise la bibliothèque **BeautifulSoup** pour analyser un fichier HTML et extraire automatiquement des informations spécifiques (titre et paragraphe descriptif).

L'objectif est de démontrer les bases du parsing HTML et de l'extraction de données structurées à partir d'un contenu web.

## Fonctionnalités

- Lecture d’un fichier HTML
- Analyse du DOM avec BeautifulSoup
- Extraction de balises ciblées (`h1`, `p` avec classe spécifique)
- Affichage des données extraites

## Technologies utilisées

- Python
- BeautifulSoup (bs4)
- Parsing HTML
